Rice Palette Proposals

Four candidate color schemes for the Hyprland + Kitty + Zsh rice. All share Monokai's role mapping (keywords red, functions green, strings yellow, numbers purple, builtins cyan, parameters orange) on a dark, blue-violet "space" base. They differ in base hue, accent saturation, and contrast. Every palette passes the same contrast rules (tools/palette.py check); the mockups below use the real hex values.

ProposalBackgroundAccents TextCommentsWeakest accent
Nebula ★#1C1B2613.24.96.4 red
Deep Field#13172714.45.27.1 red
Event Horizon#21202611.54.86.4 red
Pulsar#16151D15.44.86.3 red

Contrast is the WCAG ratio against each palette's own background. Body text is capped near 15:1 on purpose: pure white on black (21:1) causes halation on dark themes. Comments sit at 4.5:1 or above, where classic Monokai's comment color is about 3:1.

Nebula

Monokai Pro accents on a violet-tinted deep-space base. Balanced default.

local c = require("theme.colors")

hl.config({
    general = {
        gaps_in     = 6,
        border_size = 2,
        col = {
            active_border   = { colors = { c.cyan, c.purple }, angle = 45 },
            inactive_border = c.surface1,
        },
    },
    decoration = { rounding = 10, active_opacity = 1.0 },
})

for i = 1, 9 do
    hl.bind("SUPER + " .. i, hl.dsp.focus({ workspace = i }))
end
